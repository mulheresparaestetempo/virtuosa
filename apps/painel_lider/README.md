# Painel Líder

Dashboard for spiritual leaders to manage disciples, prayers, and spiritual guidance.

## Features

- Gerenciamento de discípulas
- Pedidos de oração
- Acompanhamento espiritual
- Mensagens e notificações
- Relatórios e metas
- Agendamento de cultos

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Firebase Admin SDK

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```
