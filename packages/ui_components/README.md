# UI Components

Reusable UI components for Abba Virtuosa.

## Components

- **Buttons** - Primary, Secondary, Glass buttons
- **Cards** - Verse, Prayer, Devotional, Journal cards
- **Inputs** - Text fields and inputs
- **Navigation** - Navigation widgets
- **Modals** - Dialogs and bottom sheets
- **Animations** - Fade, Scale, Slide animations
- **Indicators** - Progress bars, ratings
- **Layouts** - Common layout patterns

## Installation

```bash
flutter pub add ui_components
```

## Usage

```dart
import 'package:ui_components/ui_components.dart';

// Use components
PrimaryButton(
  label: 'Click me',
  onPressed: () {},
)
```
