# Fonts

Google Fonts used throughout Abba Virtuosa.

## Included Fonts

1. **Playfair Display** - Display/Headers (Serif)
   - Regular, Bold

2. **Cormorant Garamond** - Elegant text (Serif)
   - Regular, Bold

3. **Poppins** - Body/UI text (Sans-serif)
   - Regular, SemiBold, Bold

4. **Inter** - System/Code (Sans-serif)
   - Regular, SemiBold, Bold

## Usage

Fonts are managed by the `design_system` package and loaded in app configurations.
