### Opção 2: Deploy Automático (Recomendado)

#### A. Replit (Gratuito, Pronto em 2 min)
1. Abra: https://replit.com
2. Faça login com GitHub
3. "Create" → "Import from GitHub"
4. Cole: https://github.com/mulheresparaestetempo/virtuosa
5. Clique "Run"
6. Sua URL: https://seu-replit.replit.dev

#### B. Railway (Gratuito, $5/mês)
1. Abra: https://railway.app
2. "Create New Project"
3. "Deploy from GitHub repo"
4. Selecione: virtuosa
5. Deploy automático
6. Sua URL: https://seu-projeto.railway.app

#### C. Render (Gratuito Forever)
1. Abra: https://render.com
2. "Create +" → "Web Service"
3. Connect GitHub
4. Selecione: virtuosa
5. Root Directory: apps/painel_lider
6. Deploy
7. Sua URL: https://seu-projeto.onrender.com
