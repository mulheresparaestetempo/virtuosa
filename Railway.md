# Deploy Automático em Railway.app

## Passo 1: Abra Railroad
https://railway.app

## Passo 2: Create New Project
Clique em "Create New Project"

## Passo 3: Deploy from GitHub
Selecione "Deploy from GitHub repo"

## Passo 4: Conecte seu GitHub
- Clique em conectar GitHub
- Autorize railway

## Passo 5: Selecione o Repositório
Procure por: mulheresparaestetempo/virtuosa

## Passo 6: Configure o Diretório Raiz
Root Directory: apps/painel_lider

## Passo 7: Deploy!
Clique em "Deploy"

AGUARDE 3-5 MINUTOS

Um link automático aparecerá tipo:
https://virtuosa-production-abc123.railway.app

PRONTO! Compartilhe esse link!
