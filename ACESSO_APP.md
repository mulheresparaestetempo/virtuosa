## 🚀 COMO ACESSAR

### **OPÇÃO 1: Testar Online AGORA (Recomendado)**

**Clique aqui para fazer deploy em 2 minutos:**

1. Abra: https://replit.com
2. Faça login com GitHub (ou email)
3. Clique: "Create" → "Import from GitHub"
4. Cole este link:
```
https://github.com/mulheresparaestetempo/virtuosa
```
5. Clique "Run"
6. **Sua URL aparecerá automaticamente**
7. Compartilhe com sua equipe!

---

### **OPÇÃO 2: Rodar no Seu Computador**

**Pré-requisito:** Node.js v18+

```bash
# Clonar repositório
git clone https://github.com/mulheresparaestetempo/virtuosa.git
cd virtuosa

# Instalar dependências
cd apps/painel_lider
npm install

# Rodar em desenvolvimento
npm run dev

# Abrir no navegador
# http://localhost:3000
```

---

### **OPÇÃO 3: Usar Railroad, Railway ou Render**

**Railway.app (Grátis, $5/mês):**

**Render.com (100% Grátis):**
