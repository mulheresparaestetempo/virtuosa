# Painel Admin

Administrative dashboard for managing users, churches, content, and analytics.

## Features

- Gerenciamento de usuárias
- Igrejas e líderes
- Devocionais e cursos
- Comunidade e biblioteca
- Analytics
- Configurações do sistema

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Chart.js (Analytics)
- Firebase Admin SDK

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```
