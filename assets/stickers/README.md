# Stickers

Achievement badges and reward stickers for the Abba Virtuosa app.

## Organization

- **achievements/** - Achievement stickers earned by users
- **rewards/** - Reward badges and milestones

## Formats

- PNG with transparent background (512x512)
- SVG for scalable versions

## Naming Convention

`sticker_name_level.png` (e.g., `prayer_warrior_gold.png`)
