OPÇÃO 1: RODAR LOCAL + COMPARTILHAR (Recomendado)
================================================================================

No seu computador:

1. Abra Terminal/PowerShell
2. Navegue até a pasta:
   cd C:\caminho\para\virtuosa

3. Execute:
   cd apps/painel_lider
   npm install
   npm run dev

4. Abra no navegador:
   http://localhost:3000

5. Para compartilhar com discipuladas (mesma rede WiFi):
   - Descubra seu IP: ipconfig (Windows) ou ifconfig (Mac/Linux)
   - Compartilhe: http://SEU_IP:3000

================================================================================
OPÇÃO 2: DEPLOY ONLINE (3 minutos)
================================================================================

Escolha UMA das plataformas:

A) REPLIT (Mais Fácil)
   1. Abra: https://replit.com
   2. Clique "Create" → "Import from GitHub"
   3. Cole: https://github.com/mulheresparaestetempo/virtuosa
   4. Clique em "Run"
   5. URL será gerada automaticamente
   6. Compartilhe o link!

B) RAILWAY
   1. Abra: https://railway.app
   2. "Create New Project"
   3. "Deploy from GitHub repo"
   4. Selecione: virtuosa
   5. Deixe rodar ~5 min
   6. Copie a URL pública

C) RENDER
   1. Abra: https://render.com
   2. "Create Web Service"
   3. Conecte seu GitHub
   4. Selecione: virtuosa
   5. Root Directory: apps/painel_lider
   6. Deploy!
