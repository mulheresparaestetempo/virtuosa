## 🚀 COMO RODAR (Escolha UMA opção)

### **OPÇÃO 1: Windows** (Mais Fácil)

1. **Baixe o repositório:**
   ```
   https://github.com/mulheresparaestetempo/virtuosa
   ```

2. **Na pasta do projeto, clique 2x em:**
   ```
   START_APP.bat
   ```

3. **Espere 2-3 minutos**

4. **Abra no navegador:**
   ```
   http://localhost:3000
   ```

5. **Pronto! App funcionando! 🎉**

---

### **OPÇÃO 2: Mac/Linux**

1. **Abra o Terminal na pasta do projeto**

2. **Execute:**
   ```bash
   chmod +x START_APP.sh
   ./START_APP.sh
   ```

3. **Espere 2-3 minutos**

4. **Abra no navegador:**
   ```
   http://localhost:3000
   ```

5. **Pronto! App funcionando! 🎉**

---

### **OPÇÃO 3: Terminal (Qualquer Sistema)**

1. **Na pasta do projeto, abra Terminal/PowerShell**

2. **Execute:**
   ```bash
   cd apps/painel_lider
   npm install
   npm run dev
   ```

3. **Abra no navegador:**
   ```
   http://localhost:3000
   ```

4. **Pronto! App funcionando! 🎉**

## 🆘 PROBLEMAS?

### "Node.js not found"
Instale Node.js em: https://nodejs.org (v18+)

### "npm command not found"
Reinicie o computador após instalar Node.js

### "Porta 3000 em uso"
A app vai usar outra porta automaticamente

### "Erro ao instalar dependências"
Execute no Terminal:
```bash
npm install --legacy-peer-deps
```
