# Illustrations

SVG and raster illustrations for the Abba Virtuosa platform.

## Organization

- **onboarding/** - Onboarding flow illustrations
- **empty_states/** - Empty state graphics for features
- **features/** - Feature-specific illustrations

## Guidelines

- Use SVG format when possible for scalability
- Maintain consistent art style
- Use color palette from design system (Bordo/Dourado/Rosé)
- Naming: `snake_case_description.svg`
