# Custom Icons

Custom SVG icons not found in Material Icons.

## Organization

- Named with descriptive labels
- 24x24 or 48x48 base size
- Consistent stroke weight (2px)
- Color: Use CSS variables for theming

## Format

SVG files with `<svg>` tags optimized for Flutter/React

## Naming

`icon_name.svg` (e.g., `icon_prayer_hands.svg`)
