# Design System

Design tokens and Material Theme for Abba Virtuosa.

## Features

- **Colors** - Bordo/Dourado/Rosé palette
- **Typography** - 4 Google Fonts (Playfair Display, Cormorant Garamond, Poppins, Inter)
- **Spacing** - 8px scale system
- **Shadows** - Material Design elevation system
- **Radius** - Border radius tokens
- **Durations** - Animation durations
- **Theme** - Material 3 theme configuration

## Installation

```bash
flutter pub add design_system
```

## Usage

```dart
import 'package:design_system/design_system.dart';

// Use design tokens
Text(
  'Hello',
  style: AppTextStyles.heading1,
)
```
