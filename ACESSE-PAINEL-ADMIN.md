## 🎯 COMO USAR

### Adicionar um PDF
1. Clique na aba **"📚 Recursos"**
2. Selecione tipo: **"📄 PDF"**
3. Preencha: Título, Descrição, Link (opcional)
4. Clique em **"Adicionar Recurso"**
5. ✅ PDF aparece na lista abaixo

### Adicionar um Áudio
1. Clique na aba **"📚 Recursos"**
2. Selecione tipo: **"🎵 Áudio"**
3. Preencha: Título, Descrição, Link do áudio
4. Clique em **"Adicionar Recurso"**
5. ✅ Áudio aparece na lista

### Adicionar um Podcast
1. Clique na aba **"📚 Recursos"**
2. Selecione tipo: **"🎙️ Podcast"**
3. Preencha: Título, Descrição, Link do podcast
4. Clique em **"Adicionar Recurso"**
5. ✅ Podcast aparece na lista

### Adicionar um Livro
1. Clique na aba **"📚 Recursos"**
2. Selecione tipo: **"📖 Livro"**
3. Preencha: Título, Descrição, Link (se houver)
4. Clique em **"Adicionar Recurso"**
5. ✅ Livro aparece na lista

### Enviar um Aviso
1. Clique na aba **"📢 Avisos"**
2. Preencha:
   - Título (Ex: "Nova Meditação Publicada")
   - Mensagem (conteúdo do aviso)
   - Prioridade (📌 Baixa, ⚠️ Média, 🔴 Alta)
3. Clique em **"Enviar Aviso"**
4. ✅ Aviso é enviado para todas as usuárias
5. ✅ Aparece no histórico abaixo

## ❓ DÚVIDAS FREQUENTES

**P: Os dados são salvos?**
R: Sim! Todos os recursos e avisos são salvos em memória enquanto você está no painel. Para dados persistentes em banco de dados, use o módulo "Admin Avançado".

**P: Posso editار recursos?**
R: Por enquanto, você pode remover e adicionar um novo. Logo vamos adicionar a edição completa.

**P: Qualquer pessoa pode acessar?**
R: Sim, qualquer pessoa pode acessar. Para versão com autenticação, use a aba "Admin Completo".

**P: Como adiciono um link de PDF/Áudio/Podcast?**
R: Você pode usar links do:
- Google Drive (compartilhado)
- Dropbox
- YouTube
- Spotify (para podcasts)
- Qualquer link público
