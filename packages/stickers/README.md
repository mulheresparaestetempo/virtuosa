# Stickers Package

Stickers and achievement system for Abba Virtuosa.

## Features

- Sticker definitions and metadata
- Progressive unlocking system
- Achievement showcase
- Sharing capabilities

## Installation

```bash
flutter pub add stickers
```

## Usage

```dart
import 'package:stickers/stickers.dart';

// Display sticker
StickerWidget(
  sticker: sticker,
)
```
